01 / About

Security-minded. Hands-on. Always learning.

My background is in cybersecurity, with experience across security monitoring, network reconnaissance, vulnerability assessment, Linux and Windows security, penetration testing fundamentals, and incident response.

I'm especially interested in blue-team security and SOC work: understanding what is happening across a network, recognizing suspicious activity, investigating alerts, and improving the security posture of systems before an incident becomes a larger problem.

Through coursework, labs, independent practice, and my cybersecurity bootcamp, I've worked with tools including Wazuh, Nmap, Kali Linux, Wireshark, Burp Suite, SearchSploit, AIDE, vulnerability scanners, Windows, Linux, and Hyper-V.

My goal is to continue strengthening my detection, incident response, network analysis, system hardening, and defensive security skills while building a portfolio that demonstrates what I can actually do.
