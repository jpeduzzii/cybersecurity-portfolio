# SOC Tools

This folder contains work related to the security operations tools I have the most hands-on experience with.

My strongest area is SIEM and security monitoring. I have spent more than nine months working with Wazuh and have also used Nmap extensively for network discovery, service enumeration, and investigating systems during security labs.

---

## Wazuh

**Comfort Level: Strong**

Wazuh is the SOC tool I have the most experience with. I have worked with it for more than nine months and have used it to become more comfortable with how security events are collected, reviewed, and investigated.

### Experience

- Monitoring security events and alerts
- Reviewing endpoint activity
- Investigating alerts to determine what caused them
- Looking through event data instead of relying only on the alert description
- Identifying suspicious activity
- Connecting events from a system to the larger security picture
- Using SIEM data during incident investigation
- Working with file integrity monitoring and endpoint security concepts
- Reviewing vulnerabilities and security-related system activity

One of the things I enjoy most about SIEM work is taking an alert and figuring out what actually happened instead of stopping at the initial detection.

## Nmap

**Comfort Level: Strong**

I have used Nmap extensively for network reconnaissance and service enumeration. I am comfortable using scan results to understand what is running on a host and to determine what should be investigated next.

### Experience

- Host discovery
- TCP port scanning
- Service and version detection
- Operating system and network reconnaissance
- Identifying exposed services
- Analyzing open ports
- Enumerating services such as:
  - FTP
  - HTTP / IIS
  - SMB
  - RPC
- Using scan results to guide further investigation
- Researching discovered services and versions for known vulnerabilities
- Using Nmap as part of penetration testing and security assessment labs

I am comfortable reading Nmap output and using the results as a starting point for a larger investigation rather than treating the scan itself as the end goal.
